# 任务列表 - 影子格斗家

## 阶段1：项目基础设置

- [ ] 任务1: 初始化游戏项目
  - 创建 HTML 游戏入口文件
  - 引入必要的游戏库（Phaser 或纯 Canvas）
  - 配置开发环境

## 阶段2：核心游戏场景

- [ ] 任务2: 创建游戏主场景和关卡基础结构
  - 设置游戏画布和渲染环境
  - 创建背景层（静态场景）
  - 实现玩家角色基础渲染

## 阶段3：光影系统

- [ ] 任务3: 实现光源系统
  - 创建光源对象（可移动）
  - 实现光源位置预设（上方/侧面/斜射）
  - 添加光源切换 UI

- [ ] 任务4: 实现影子渲染系统
  - 计算并渲染玩家影子
  - 实现三种影子形态（人形/剑形/巨手）
  - 影子跟随角色移动

## 阶段4：玩家控制系统

- [ ] 任务5: 实现玩家移动和攻击
  - WASD 移动控制
  - 空格键攻击
  - 三种影子形态的攻击动画

## 阶段5：敌人系统

- [ ] 任务6: 实现敌人影子AI
  - 创建敌人影子对象
  - 实现敌人追踪行为
  - 添加敌人攻击判定

- [ ] 任务7: 战斗碰撞检测
  - 玩家影子攻击敌人
  - 敌人影子攻击玩家
  - 生命值和伤害系统

## 阶段6：关卡和游戏流程

- [ ] 任务8: 关卡设计和加载
  - 设计第一个关卡布局
  - 添加关卡目标（击败敌人/到达终点）
  - 实现关卡切换

## 阶段7：UI 和反馈

- [ ] 任务9: 游戏 UI 系统
  - 生命值显示
  - 分数显示
  - 关卡过渡动画

- [ ] 任务10: 视觉和音效反馈
  - 攻击特效
  - 受伤闪烁效果
  - 背景音乐和音效

## 阶段8：测试和完善

- [ ] 任务11: 游戏测试和优化
  - 完整游戏流程测试
  - 性能优化
  - 修复已知问题
