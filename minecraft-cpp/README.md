# VoxelCraft C++17 · 我的世界 3D 体素沙盒游戏

基于 **C++17 核心体素引擎** + **零依赖 WebGL 3D 像素材质渲染** 打造的浏览器可玩《我的世界》沙盒游戏。

## ✨ 核心特性

- **C++17 地形生成与物理核心 (`src/voxel_core.cpp`)**：
  - 64×40×64 3D 体素世界，FBM 分形噪声地形、沙滩湖泊、橡树森林、地下金矿/钻石矿、基岩层与出生点萤石观景台
  - 3D DDA 射线方块拾取、玩家 AABB 重力/跳跃/水下浮力/飞行碰撞物理、TNT 球形爆破毁灭算法、二进制存档 (`world_save.bin`)
- **WebGL 3D 实时渲染 (`web/index.html`)**：
  - 自绘 256×256 像素风方块图集（草地、泥土、石头、圆石、原木年轮、树叶、木板、沙子、动态水面、半透明玻璃、红砖、萤石、TNT、钻石矿、金矿、基岩）
  - 区块剔除网格优化 + 顶点环境光遮蔽 (AO) + 昼夜交替光照 + 水下蓝雾 + 方块破坏碎片粒子
  - 10 格快捷物品栏，支持点击放置与 **TNT 点燃引爆**

## 🚀 在 Ubuntu / Termux 启动

```bash
cd minecraft-cpp
chmod +x run.sh
./run.sh
```

启动后在浏览器打开 **http://127.0.0.1:8081**。
