# 《火柴人：遗迹之战》

一款原创的 2.5D 火柴人即时战斗与军团经营小游戏，纯 HTML、CSS、Canvas 实现，不依赖外部资源。

## 战役与角色

- **8 个战役关卡**：风蚀峡谷、赤砂驿站、断桥要塞、古树哨所、影月回廊、封印高塔、熔岩巨门、赤曜王座。
- **每关胜利解锁一名新角色**：轻剑士、巡林弓手、磐石枪卫、城垛盾卫、影刃刺客、星火法师、遗迹巨人、雷霆骑士。
- **亲自操控青岚**：在有远近纵深的战场中前后左右移动、躲开攻击并挥剑；AI 军团负责采矿、列阵与协同作战。
- 战役进度和已解锁角色自动保存在浏览器本机的 `localStorage` 中。

## 操作

| 按键 | 操作 |
|---|---|
| `W A S D` / `↑ ↓ ← →` | 操控青岚在战场中移动（包含前后纵深） |
| `J` / `空格` | 持续挥剑攻击 |
| `1`–`9` | 征募已解锁的对应兵种 |
| `C` | 切换坚守 / 突进军令 |
| `H` | 使用冲锋号角 |
| `F` | 切换 1× / 2× 速度 |
| `P` / `Esc` | 暂停或继续 |
| 触屏 | 使用战场内的方向键和挥剑按钮 |

## 本地运行

直接打开 `index.html`，或在仓库根目录运行：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080/stickwar/`。

## 项目文件

- `index.html` — 战役地图、兵种管理与触屏控件
- `style.css` — 响应式战役 UI、角色解锁卡片和触屏控制器
- `game.js` — 伪 2.5D 地面投影、手动角色控制、挥击动画、兵种 AI、8 关战役与存档
