# 《火柴人：遗迹之战》

一款原创的火柴人即时战略小游戏，使用原生 HTML、CSS 和 Canvas 编写，无框架、无外部资源，浏览器打开即可游玩。

## 玩法

- 派遣矿工在金脉与要塞之间往返，带回黄金。
- 征募剑士、弓手、枪卫和巨人，组成最多 20 人的军团。
- 在「坚守阵线」与「全军突进」之间切换，抵挡敌军波次并摧毁右侧的赤曜遗迹。
- 升级军械和矿镐；冲锋号角会短暂强化全军。
- 要塞被摧毁即失败，敌方遗迹被摧毁则胜利。

## 操作

| 按键 | 操作 |
|---|---|
| `1`–`5` | 征募对应兵种 |
| `A` | 切换坚守 / 突进 |
| `H` | 使用冲锋号角 |
| `F` | 切换 1× / 2× 速度 |
| `P` / `空格` / `Esc` | 暂停或继续 |
| 点击己方士兵 | 查看兵种与生命值 |

## 本地运行

直接打开 `index.html`，或在仓库根目录运行：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080/stickwar/`。

## 项目文件

- `index.html` — 游戏页面与交互面板
- `style.css` — 响应式界面、开场与战报样式
- `game.js` — Canvas 绘制、采矿经济、兵种 AI、战斗、波次与升级逻辑
