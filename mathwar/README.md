# 《数学之战》 · Math Battle

植物大战僵尸 × 数学运算的塔防小游戏。纯 HTML + CSS + Canvas，没有任何依赖，双击 `index.html` 就能玩。

## 核心规则

- **阳光 = 积分**：击杀僵尸不产出积分，积分靠阳光自动增长和阳光植物生产。
- **僵尸头顶的数字就是它的血量**：子弹让数字**向 0 靠近**——
  - 负数僵尸被「1」打中：`-3 → -2`
  - 正数僵尸被「1」打中：`+3 → +2`
  - 归零（0）立刻死亡。
- **特殊子弹**：`+2` 只对负数有效（打正数反而加血），`-2` 只对正数有效，`×0` 直接归零秒杀。
- **地雷只能种在草地第一行 / 最后一行**，选卡后画布会高亮可放置的行：
  - `×1`：准备 15 秒，踩中后数字强制为 1 再减 1 → 直接归零。
  - `÷2`：准备 10 秒，踩中后数字减半（向 0），`±1` 直接归零。
- 僵尸走到左边房子扣 1 生命，生命归零则失败。

每关 ★★★ 条件：通关 + 生命不减 + 在目标秒数内通关。进度存在 `localStorage`（`mathwar_save_v1`）。

## 操作

| 操作 | 说明 |
|---|---|
| 点击卡片 / 数字键 `1-9` `0` `Q W E R` | 选择植物 |
| 点击草坪 | 种植 |
| `S` | 铲子模式 |
| `P` / 空格 | 暂停 |
| `F` | 2× 变速 |
| 右键 / `Esc` | 取消选择 |

## 部署

本游戏是纯静态页面，仓库已配置好自动发布：

1. 打开仓库 **Settings → Pages → Build and deployment → Source**，选择 **GitHub Actions**（只需点一次）。
2. 之后每次向 `main` 推送改动，`.github/workflows/build.yml` 都会重新构建并把 `mathwar/` 一起发布。

发布后的地址：

- 本游戏：`https://qiqihelp.github.io/123/mathwar/`
- 仓库主站（回声之谷）：`https://qiqihelp.github.io/123/`

> 如果暂时不想启用 Pages，也可以用 jsDelivr 直接读仓库里的文件（免部署）：
> `https://cdn.jsdelivr.net/gh/qiqihelp/123/mathwar/index.html`

## 本地运行

```bash
cd mathwar
python3 -m http.server 8080
# 打开 http://localhost:8080
```
